## Schema

File: `benchmark_queries.jsonl` — one JSON object per line.

```json
{
  "id": "bazi_L2_042",
  "domain": "bazi",
  "difficulty": "L2",
  "query": "甲木日主生在寅月，官星不透财星多，走庚申大运，2026丙午年的财运和事业走向如何？",
  "expected_dimensions": ["财运", "事业"],
  "reference_answer_hints": [
    "需要分析财星旺衰",
    "大运庚申与日主关系",
    "流年丙午引动"
  ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique ID: `{domain}_L{level}_{3-digit-sequence}` |
| `domain` | string | One of: `bazi`, `ziwei`, `fengshui`, `dream`, `mianxiang`, `qimen`, `xingming`, `zeri` |
| `difficulty` | string | `L1` (basic), `L2` (intermediate), or `L3` (comprehensive) |
| `query` | string | The user's fortune-telling question (Chinese, 20–120 chars) |
| `expected_dimensions` | string[] | 2–4 analysis dimensions the query touches |
| `reference_answer_hints` | string[] | 2–4 hints for correct analysis direction |

## Difficulty Levels

### L1 — Basic (基础)
Simple, generic questions that a layperson would ask. Uses everyday language, no specialized terminology required. Examples: "How is my wealth luck this year?" "What does this dream mean?"

### L2 — Intermediate (进阶)
Questions requiring specific domain knowledge with concrete parameters. Includes elements like Heavenly Stems/Earthly Branches, star names, facing directions, etc. The user demonstrates some knowledge of the field.

### L3 — Comprehensive (综合)
Multi-dimensional, complex scenarios requiring deep reasoning across multiple analysis angles. Involves significant life decisions (career change, marriage, business). Combines natal chart + luck pillars + annual influences.

## Query Composition

Queries are designed to reflect real user diversity:

- **Gender mix**: ~50% male, ~50% female perspectives
- **Age range**: 20s (career), 30s (marriage/family), 40s (midlife), 50s+ (retirement/health)
- **Regional references**: Occasional mentions of Chinese cities/regions (Beijing, Shanghai, Guangdong, Dongbei, Sichuan, Zhejiang)
- **Language style**: Mix of colloquial and semi-professional, authentic to how real users address fortune-tellers

### Counting

```bash
# Total queries
wc -l benchmar_queries.jsonl

# Count by domain
jq -r '.domain' benchmar_queries.jsonl | sort | uniq -c | sort -rn

# Count by difficulty
jq -r '.difficulty' benchmar_queries.jsonl | sort | uniq -c | sort -rn

```
