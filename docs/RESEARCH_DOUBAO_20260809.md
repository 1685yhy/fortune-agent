# 豆包（Doubao）对话系统设计调研报告

> 调研时间：2026-08-09｜用途：易理明灯对话系统对标优化｜来源分级：【官方一手】【三方分析】【传闻/推测】

## 一、长程记忆与用户画像

### 记忆机制（官方 FAQ，2025-10 上线记忆功能）
- **记忆内容**：从对话提炼的个人兴趣/偏好 + 用户主动要求记住的内容；只记文本，不含图片/文件
- **双轨生成**：显式记忆（"请记住…"实时保存刷新）+ 隐式记忆（自动提炼，周期性滚动刷新，非实时）
- **容量**：总量有限，超限后**最近覆盖最早**（FIFO）；各智能体记忆互相独立
- **交互**：设置-记忆页开关 + **左滑删单条** + 一键清空 + 聊天中说"忘记 X"即可删；明确"关开关≠删记忆""删聊天≠删记忆"

### 技术范式（火山官方开源方案 = 字节工程范式）
- **事实提取**：强推理模型（DeepSeek-R1 / doubao thinking）从对话抽事实，多步逻辑校验降幻觉
- **存储**：向量库（VikingDB/OpenSearch）+ 结构化条目；**混合检索**（文本+向量加权融合，内存省 75%）
- **召回**：超窗口或新会话时，按向量相似度召回相关记忆注入生成；含画像抽取、意图识别、**记忆冲突处理**、清理模块
- **分工**：强推理模型提取 + 对话模型生成（提取与应答分离）

### 对命理产品的要点
画像（常问方向/偏好/已算信息）与事实（生辰/性别/排盘结果）分离；新会话自动挂载画像。

## 二、对话理解（模型端到端）
- 多意图拆解+动作编排：一句"帮我哄孩子睡觉"联动多个任务；可识别倒装/双重否定/模糊语义
- **多粒度语义**：表层意图（显性）+ 隐层意图（未言明约束）+ 场景意图（前序对话绑定）
- **结构化意图输出**：intent_understanding 接口把模糊 query 转 JSON（如 {category, price_range, occasion}）再交下游
- 规则只做：模糊指令先确认（防误操作）、输出格式硬约束、兜底

## 三、上下文管理
- 模型层：豆包 1.8 256K 窗口 + **原生智能上下文管理**（清除低价值历史工具调用）；2.0 三级分层索引（语义/结构/细节，细节层 token 配额）
- App 会话级：约**最近 20 轮**上下文（会话=记忆边界，新建对话清历史）
- 工程层：Session Cache（每用户独立上下文缓存）+ Prefix Cache（复用长 system prompt）——短时记忆靠缓存、长时记忆靠 RAG
- 应用层三层兜底：最近 N 轮原文 + 结构化摘要 + 长窗口压缩（降 70% token 且提质量）

## 四、联网搜索（"边想边搜"）
- 2025-03 起**取消独立联网按钮**，与深度思考合并：模型推理中**自主决定何时搜、搜几轮**（通常 2-3 轮：问题分析→初步信息→深挖→不确定再搜→综合）
- 接口层：web_search 挂载为 **tool，模型决定触发**；返回体带实际检索词（web_search_call）与调用计数
- **答案级引用**：URL 挂对应句子（annotations），非另附来源列表
- 底层：Bytespider 爬虫→内容库→检索池；2026-07 上线搜索开放服务（独立 API，月 500 次免费额度）
- 已知取舍：简单问题也可能机械多轮搜索

## 五、个性化
- API 层字段化：`system_role`（人设）、`bot_name`（改名）、`speaking_style`（自然语言定风格："说话像林黛玉"）、character_manifest（强人格）
- 语音 2.0：语速/情绪/声线/风格/方言指令级控制
- 用户侧：资料编辑（年龄/性别/城市/职业/**兴趣标签≥5 项**）构建初始画像

## 六、工具调用
- 标准三步：定义工具（名+参数描述）→ **模型只决策**（调哪个/传什么参）→ 服务端校验白名单+参数后执行→回填→生成
- 服务端**不能信任模型返回**；工具 description 决定触发率（90% 不调用源于描述笼统）
- MCP Hub/Marketplace；Agent 化（边想边搜/DeepResearch/GUI 操作）

## 七、产品交互
- **Onboarding**：欢迎语拟人化开场（"嗨，我是你的新朋友豆包…"）+ 推荐问题卡 + 兴趣标签勾选（≥5）轻量采集
- **打断**：回答中直接输入新问题=立即发送+旧回答自动结束（打断做得最轻量的产品）
- **续聊**：追问/收藏→继续对话；新对话即清上下文
- **反馈**：点赞 + 长按"不感兴趣"（选原因：不准确/无关/缺参考）+ 文字反馈表单（选问题类型：事实错误/逻辑中断/数据过时/未覆盖要点，生成追踪编号）+ 截图反馈
- **语音**：实时语音全双工（Seeduplex，可随时打断判停；满意度 4.36/5 vs GPT-4o 3.18/5）

## 八、对我们的启示（10 条）
1. 记忆三层建模：会话原文→画像（常问方向/偏好）→事实（生辰/性别），画像与事实分离
2. 显式记忆优先+滚动刷新双轨；**记忆冲突处理**（后说为准+确认）
3. "记住我"三件套必抄：开关+左滑删+清空+聊天中删除；明示"删聊天≠删记忆"
4. 一句话多需求→意图拆解+动作编排（模型为主，规则兜底，JSON 化）
5. 排盘做标准工具三步，**模型只决策不计算**；工具 description 写清触发条件
6. "边想边搜"适合命理+时事：深度思考即自动联网，答案级引用；信源分级（历法/黄历源优先）
7. 反馈闭环小时级：赞踩+原因分类+文字表单+截图→复核队列→prompt 修正样例
8. 人设参数化（大师严肃派/温和陪伴派可配置），不写死
9. Onboarding 兴趣化采集（分步+示例+可跳过+边聊边补），非审问式
10. 上下文三层兜底：最近 N 轮原文+结构化摘要+长窗口压缩；会话=记忆边界，跨会话靠"追问/收藏"
