# 腾讯元宝（Yuanbao）对话系统深度调研报告

> 调研时间：2026-08-09｜来源分级：【官方一手】【产品评测】【传闻/推测（已标注）】

## 一、长程记忆（最有价值的发现）

### Hy-Memory 六层记忆框架（混元团队 2026-05 发布，官方一手）
- **L1 原始痕迹**：完整对话记录（只存不直接用）
- **L2 原子事实**：把口语压成可检索关键事实（"用户在深圳"）——**别把原文塞上下文**
- **L3 身份画像**：稳定长期偏好与人设
- **L4 会话摘要**：本轮长会话现场压缩精华
- **L5 心智模型**：行为中抽象出认知/价值观/决策逻辑
- **L6 前瞻意图**：异步沉淀下一步意图预测
- 检索时按提问精准调用对应层级，避免注意力被无关原文稀释

### System1/System2 双系统
- **System1**：用户回车后 1 秒内实时抽事实、更新画像与摘要（L1-L4），下一句对话立即可用
- **System2**：后台异步运行，沉淀心智模型（L5-L6），不阻塞主链路

### 演化链（supersedes 指针）
用户观念阶段性改变时，新旧记忆串成**演化链**——既记住最新结论又能复盘态度演变，**避免"新覆盖旧丢历史"**。
性能：记忆数量 -70%、信息密度 +45%、token 消耗 -35%；LongMemEval 85.20 分。

### 腾讯云 Memory 产品化（官方文档）
- 时效可配 1~999 天（默认 30 天），超期自动删除
- 用户可**展示/修改/删除/清空**记忆
- 两类策略：**画像记忆**（身份/关系/偏好，跨会话一致性）+ **事件记忆**（行为/决策/经历，里程碑回溯）

## 二、对话理解
- 搜索场景：Query Planning **两阶段 LLM 改写**（SFT 学意图拆解 → RL 用检索反馈强化）；把复杂需求拆多个 query
- Agentic RAG：Planning 任务拆解 + Reflection 动态调优 + 多轮反馈
- 通用对话的多意图拆解**无公开资料**；用户反馈元宝存在意图识别偏差
- Hy-MultiTurn 基准（六维多轮理解：约束记忆/动作抑制）；团队公开判断"**模型如何记忆将是 2026 大模型核心主题**"

## 三、上下文管理
- 混元 Hy3：256K 窗口 + 上下文 Cache（缓存命中价格 1/3）；多轮 Agent 长记忆=典型场景
- **对话分组**（官方）：按主题/项目分组，**每组独立提示词**（语气/语言/格式），上下文物理隔离
- 用户实测反馈：元宝"聊着聊着会忘掉前几轮"（上下文工程被吐槽）

## 四、联网搜索
- 接入**微信搜一搜、搜狗搜索**等；公众号内容是差异化优势
- 开启"联网搜索"开关后**模型按语义判断是否触发**（带时效词更易触发）
- 引用：正文**下划线来源标注**（《公告 2026 年第 8 号》/《公众号 XX 6 月 28 日推文》）+ 参考资料列表可展开跳转
- **深度研究模式**：复杂问题首答后自动附"深度研究该问题"入口 → 自动查数百篇资料生成 3000+ 字报告（含大纲/思维导图/引用底座）
- 搜索 API：混元 `search_enabled: true` 参数或 search 工具

## 五、个性化
- **重塑角色**：同角色多个"分身"，每个分身独立记忆性格
- 对话分组 = 语气/话术控制层（每组独立提示词）
- 双模型双模式：快思考（Turbo）vs 深度思考（T1/R1，显示思维链+思考时间），会话内可切
- 角色 AI：音色克隆（"温柔静静"/"活泼七七"）

## 六、工具调用
- 插件召排（向量召回+rank，官方称召回率 100%）→ Function Calling 抽槽位 → API 调用 → 质量控制
- 混元 API Function Calling 兼容性细节：消息必须以 user/tool 结尾；不支持 parallel_tool_calls
- 正向 **MCP 标准化**演进（企业 MCP Hub）

## 七、产品交互
- **对话接力**（官方）：回答一键转发微信，接收方点"和元宝继续聊"→ 新设备/新用户基于原对话继续，无需重交代上下文
- **临时对话（阅后即焚）**：一次性提问不进主上下文，退出不留痕（隐私设计）
- 开场白 + 推荐问题（智能体平台可配）
- 微信聊天记录导入 → 自动生成相关问题供选择（追问机制）
- 历史对话检索、对话长图/节选分享、电脑版上下箭头跳转提问
- **隐私**："体验优化开关"**默认关闭**（默认不用用户数据优化模型），数据管理页可查

## 八、对我们的启示（10 条）
1. 记忆分层（原文/原子事实/画像/摘要）+ **用户可查看/修改/删除/清空** = 命理产品信任基建
2. 原子事实抽取，别把原文塞上下文（"用户：女，1990 年生，已婚，关注事业亲子"）
3. **演化链**替代"新覆盖旧"：用户反复问同一事（换不换工作），立场变化串成链，下次带上演变史
4. System1 快记（1 秒内）+ System2 后台深加工（画像/偏好沉淀），不阻塞对话
5. 命理解读附来源（黄历/星历/古籍/百科多源，每条结论标注出处+免责）
6. 复杂问题**快答 + 自动升级深度模式**（命理：运势速览 → 深度排盘逐步展示）
7. 对话分组隔离上下文（事业/感情/健康分轨）+ 临时对话模式（即问即走轻咨询）
8. 回答后自动生成相关问题（驱动多轮对话，等用户自己会问就晚了）
9. 快思考/深度思考双模式开关（精批展示推演步骤，显专业）
10. 隐私开关默认关闭 + 阅后即焚临时对话（合规与口碑双保险）
