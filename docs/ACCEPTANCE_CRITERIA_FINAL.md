## 验收流程

1. **代码审查** → Agent 审查代码规范、安全、性能
2. **MCP 逐页测试** → 4 Tab 逐一导航+交互+截图
3. **编译错误检查** → mp_getLogs 确认零错误
4. **API 连通检查** → 所有端点返回200
5. **UI 对比度验证** → 程序化检查 + 目视确认
6. **问题修复** → 发现一个问题修复一个
7. **复验** → 修复后重新测试确认
