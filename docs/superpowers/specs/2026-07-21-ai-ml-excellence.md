# 易理明灯 v5.0 — AI/ML 顶级能力路线图

> 原则: 竞品拼的是"有没有"，我们拼的是"有多准、多懂你、多聪明"
> 核心理念: 算命是壳，AI 是核。不做算命工具，做 AI 命理引擎。

---

## 一、当前 AI 能力盘点

| 能力 | 现状 | 竞品水平 |
|------|------|------|
| 排盘引擎 | ✅ 规则引擎，100% 准确 | 问真/易奇同等 |
| RAG 知识库 | ✅ BGE-M3 + ChromaDB | 竞品无 RAG |
| LLM 解读 | ✅ DeepSeek v4-pro | 竞品用模板 |
| 意图识别 | ✅ 关键词 + LLM | 竞品无/关键词 |
| 用户记忆 | ✅ JSON 文件 | 竞品无 |
| 情绪感知 | ⚠️ 基础关键词检测 | 竞品无 |

## 二、AI/ML 能力矩阵（按用户感知度排序）

### Level 1: 让用户觉得"准" — 即刻感知

#### 1.1 个性化调参模型
**技术**: Few-shot fine-tuning + 用户反馈 RLHF
**用户感知**: "这个 App 越来越懂我了"
**实现**:
```
用户每次对话后:
  ├─ 点赞/踩 → 强化学习信号
  ├─ 追问次数 → 信息完整性信号  
  └─ 重复问同一问题 → 未满足信号

模型层面:
  ├─ LoRA 微调 DeepSeek 输出风格（匹配用户偏好）
  ├─ RAG 检索权重调整（用户关心的领域加权）
  └─ 报告深度自适应（新手用简化版，进阶用专业版）
```

**验收标准**:
- [ ] 用户使用 3 次后，回答风格与第一次有明显个性化差异
- [ ] 点赞率从基线提升 ≥ 15%
- [ ] 追问率下降 ≥ 20%

#### 1.2 命例相似度匹配
**技术**: 对比学习 + 向量检索
**用户感知**: "和我同格局的人后来都怎么样了"
**实现**:
```
用户排盘 → BGE-M3 嵌入 → 44k 命例库相似检索:
  ├─ 日主相同 + 格局相似 → Top-10 相似命例
  ├─ 大运相同 → 同期对比
  └─ 输出: "和你同格局的 100 人中，有 73% 在 35-40 岁财运上升"
```

**验收标准**:
- [ ] 相似命例检索延迟 < 500ms
- [ ] Top-10 相似度 > 0.85 (cosine)
- [ ] 用户评分 ≥ 4/5

#### 1.3 实时情绪感知引擎
**技术**: BERT-based 中文情感分析 (fine-tuned on 命理对话)
**用户感知**: "它居然知道我今天心情不好"
**实现**:
```
用户每条消息 → 情感分类器 → 
  ├─ 焦虑: 先安抚再分析，语速放慢
  ├─ 兴奋: 同频共振，用感叹号
  ├─ 悲伤: 温暖陪伴，不提负面预测
  ├─ 愤怒: 不正面冲突，转移焦点
  └─ 平静: 标准分析模式

情绪追踪:
  ├─ 月情绪曲线 → 和流月运势交叉对比
  └─ 异常检测: 连续低落 > 7天 → 推送心理关怀内容
```

**验收标准**:
- [ ] 情绪分类准确率 ≥ 85% (vs 人工标注 500 条)
- [ ] 情绪感知后用户继续对话率 ≥ 70%
- [ ] 危机信号识别率 ≥ 95%（自伤/自杀语言模式）

### Level 2: 让用户觉得"超出预期" — 使用 3 次后感知

#### 2.1 命运推演引擎
**技术**: Counterfactual reasoning + 规则引擎 + LLM
**用户感知**: "原来选 A 和选 B 命运真的不一样"
**实现**:
```
用户输入: "我该接受上海的 offer 还是留在北京？"

系统推演:
  方案 A (上海):
    ├─ 八字: 东方木旺，对日主甲木有利
    ├─ 流年: 2026 丙午，午在南方，得地
    ├─ 大运: 当前大运与东南方呼应
    └─ 结论: 去上海事业发展更好，但注意财务规划

  方案 B (北京):
    ├─ 八字: 北方水旺，泄木气
    ├─ 流年: 丙午火旺，水克火，需努力
    ├─ 大运: 大运与北方不协调
    └─ 结论: 留北京需要更多努力，但人际关系基础好

  对比输出:
    ├─ 事业发展: 上海 > 北京
    ├─ 财务收益: 上海 > 北京
    ├─ 人际关系: 北京 > 上海
    └─ 综合建议: 去上海，但保持北京人脉
```

**验收标准**:
- [ ] 至少 3 种方案推演
- [ ] 每种方案有可量化的对比维度
- [ ] 推演结果标注"此为命理推演，非确定性预测"

#### 2.2 命运异常检测
**技术**: 统计异常检测 + 规则引擎
**用户感知**: "它不仅告诉我会发生什么，还告诉我和别人比哪里不一样"
**实现**:
```
用户排盘 → 44k 命例库统计基线:
  ├─ 同龄同性别财运分布 → 用户在哪个百分位
  ├─ 同格局婚姻年龄分布 → 用户的婚龄是否偏晚
  ├─ 同大运健康趋势 → 用户是否需要额外关注
  └─ 输出: "你的财运在同龄人中属于前 20%，但婚姻可能比平均晚 3-5 年"
```

**验收标准**:
- [ ] 至少 5 个维度的对比分析
- [ ] 每个对比有统计显著性标注
- [ ] 数据库覆盖 ≥ 10,000 例

#### 2.3 自进化知识库
**技术**: Active learning + 用户反馈驱动更新
**用户感知**: "这个 App 的知识库在变聪明"
**实现**:
```
用户反馈循环:
  ├─ 👍 高赞解读 → 纳入正面训练集
  ├─ 👎 低分解读 → 人工审核 → 修正知识库
  ├─ 新问题频繁出现 → 触发知识库扩展
  └─ 每月: LoRA 微调 + RAG 权重更新

知识库自检:
  ├─ 自动发现矛盾: 两条古籍解读冲突 → 标记人工审核
  └─ 时代表达更新: 古文 → 现代中文 → 用词与时俱进
```

**验收标准**:
- [ ] 月度知识库更新自动化
- [ ] 矛盾检测覆盖率 ≥ 90%
- [ ] 用户评分月度环比提升

### Level 3: 让用户觉得"这是未来" — 长期感知

#### 3.1 多模态输入
**技术**: Vision Transformer + 面相分析
**用户感知**: "拍张脸就能看面相？"
**实现**:
```
用户拍照 → 面部关键点检测 → 面相分析:
  ├─ 五官: 眉/眼/鼻/口/耳 → 特征提取
  ├─ 气色: 肤色分析 → 健康状况推测
  ├─ 痣相: 面部痣点检测 → 位置解读
  └─ 配合八字: 面相+八字交叉验证
```

**验收标准**:
- [ ] 面部关键点检测准确率 ≥ 95%
- [ ] 面相分析结果可解释（每个结论有依据）
- [ ] 隐私声明：面部数据不上传，端侧处理

#### 3.2 语音命理师
**技术**: Whisper + TTS + 情感语音合成
**用户感知**: "可以和它语音聊天"
**实现**:
```
语音输入 → Whisper 转文字 → 命理分析 → TTS 输出:
  ├─ 支持口语气息（"嗯""那个"）自然对话
  ├─ 情感适配语音（开心时语调轻快，低落时温柔）
  └─ 背景音适配上（分析中播放舒缓古琴）
```

#### 3.3 命理数字孪生
**技术**: 时序预测 + 概率图模型
**用户感知**: "它预测的事情真的在发生"
**实现**:
```
每次交互 → 建立用户命理 Profile:
  ├─ 用户报告过的事件 → 和命理预测对比
  ├─ 准确/不准确的追踪 → 个人校准模型
  └─ 年度回顾: "去年预测你的财运上升，实际收入增长 20%"
```

## 三、技术架构升级路径

```
当前 v3.1                     v5.0 目标                      v6.0 愿景
──────────────────────────────────────────────────────────────────
规则引擎 (Python)    →    规则引擎 + LoRA 微调       →    端侧推理 (CoreML/TFLite)
BGE-M3 (GPU)         →    BGE-M3 + 对比学习          →    多模态 embedding
DeepSeek API         →    DeepSeek + 反馈微调          →    混合本地+云端
关键词情绪           →    BERT 情绪分类器             →    多模态情绪感知
JSON 文件记忆        →    SQLite 结构化记忆           →    向量记忆库
无反馈循环           →    用户反馈驱动更新            →    自进化系统
```

## 四、ML 模型训练计划

| 模型 | 训练数据 | 方法 | 周期 | GPU 需求 |
|------|------|------|------|------|
| 情绪分类器 | 5,000 标注样本 | BERT fine-tune | 1 周 | RTX 4070 ✅ |
| 个性化 LoRA | 用户反馈数据 | RLHF | 持续 | RTX 4070 ✅ |
| 对比学习 embedding | 44k 命盘 + 27k 古籍 | InfoNCE | 1 周 | RTX 4070 ✅ |
| 面相关键点 | 公开数据集 | 迁移学习 | 2 周 | RTX 4070 ✅ |
| 语音合成 | 开源 TTS | fine-tune | 1 周 | RTX 4070 ✅ |

**所有模型可用本地 RTX 4070 训练。不需要额外 GPU 服务器。**

## 五、验收总则

### AI 能力验收
- [ ] 排盘准确度 vs 问真: 100% (已达成 ✅)
- [ ] 情绪分类准确度: ≥ 85%
- [ ] 命例相似度检索: Top-10 similarity ≥ 0.85
- [ ] 个性化模型: 3 次使用后风格可感知变化
- [ ] 异常检测: 5 维度对比分析

### 用户体验验收
- [ ] 盲测: 10 个用户，和真人命理师对比，70%+ 认为 AI 更好
- [ ] 留存: 7 日留存 ≥ 40%，30 日留存 ≥ 25%
- [ ] 分享率: ≥ 15% 用户生成分享卡片
- [ ] NPS: ≥ 50

### 技术验收
- [ ] API 响应 < 60s (八字分析)，< 5s (其他)
- [ ] 模型推理 < 200ms (本地)，< 2s (云端)
- [ ] 错误率 < 1%
- [ ] 系统可用率 ≥ 99.5%
