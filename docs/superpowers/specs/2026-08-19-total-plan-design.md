# 易理明灯 — 总规划设计（Spec）

> 2026-08-19 · 经 brainstorming 流程与 PM 逐项确认 · 本 spec 是实施依据

## 1. 定位与架构

**双轮驱动**：
- **功能轮**（确定性，问真同级精度）：排盘/大运/流年/神煞/称骨/合盘/择吉/取名/万年历/论财事业健康——免费引流
- **对话轮**（我们独有，问真没有）：内置 AI 对话——功能结果 + 对话解读，增值付费

关系：功能免费引流 → 对话增值付费。五层架构：L1 排盘引擎 / L2 确定性功能 / L3 内容资产 / L4 前端设计升级 / L5 对话能力+额度体系。

## 5. L4 前端设计升级（墨韵基准升级，方向已确认 A）

- 范围：排盘结果页（四柱盘面/大运时间线/神煞标签/五行进度条/交运司令/干支关系）/ 测算 tab 重设计（分组：看我的/问事求助/关系缘分/进阶工具）/ 对话结构卡
- 方法：wechat-miniprogram-design-skill 设计流程 + 组件化原型 + vision 多轮对照 + 真机验收

## 6. L5 对话能力 + 额度体系

### 免费额度
- 免费用户：确定性功能全免费 + 对话 15-20 条/日
- 超额度：**不硬断**——降级精简模式（免费模型）+ 引导开通会员

### 会员分级（定价已确认 19.9 起）
| 层级 | 价格 | 包含 |
|---|---|---|
| 基础会员 | 19.9/月 | 对话合理不限（成本封顶）+ 深度解读 + 知识解析 |
| 高级会员 | 39.9/月（建议） | 基础全部 + 论财/论事业/论健康 + 多盘对比 + 五行能量详解 + 名人库全量 + 流年流月详版 |

### 成本封顶机制（盈利保障）
- 会员对话 100 条/日上限（正常人用不到）+ 超额自动降级 GLM-4-Flash
- 成本测算：重度用户（100 条/日）高峰时段月成本 ~18 元 < 19.9 会员费；普通用户 3-6 元
- 确定性功能 0 成本 + 深度报告另计费 → 毛利 30-70%

## 7. 模型使用策略（角色矩阵）

| 场景 | 模型 | 说明 |
|---|---|---|
| 排盘/大运/神煞/称骨/干支关系 | 不用模型 | 纯规则 0 成本 |
| 合盘缘语/择吉说明/推荐追问 | 免费模型 GLM-4-Flash | 已验证可用（现有智谱 key） |
| 对话/深度解读/论财论事业论健康 | 主模型 deepseek-flash | 付费体验核心 |
| 超额降级/精简模式 | 免费模型 | 保底不中断 |

**备注（PM 确认的修正）**：解读的骨架/风格/术语/温度由预设 prompt 决定（约 90%），模型差异仅在执行质量（约 10%——生硬/偶尔跑偏）。**降级体验差距可控，付费分层主要靠功能门控而非模型质量差**。

## 8. 红线（不可触碰）

- **对话向量库只增不改**（FAISS 276 万条 + 古籍库）：不重建/重编/迁移，只能增量添加
- 生产数据库结构变更必须带迁移+回滚方案
- 问真 API 调用限速（防封号）：间隔 1-2s、批次暂停、遇风控立即停

## 9. 流程承诺（不拍脑袋）

1. **依据先行**：每项功能标注来源（问真对标数据/已提取资产/测试库）
2. **设计走技能流程**：设计技能（Mode C）→ 组件化原型 → 多轮 vision 对照（原版基准+墨韵基准）→ 达标才实施
3. **实施带测试**：对齐问真测试库/单元测试，验证有证据
4. **交付走验收**：体验版 → PM 真机验收 → 反馈迭代

## 10. 里程碑与验收

| 阶段 | 交付 | 验收 |
|---|---|---|
| L1 排盘闭环 | 起运 100% + 神煞全量 + 干支关系 | 测试证据报告 |
| L2 功能批 | 每功能+体验版 | 真机验收 |
| L4 设计升级 | **组件原型先行**（vision 达标后实施） | 原型确认→再开发 |
| L5 额度+对话 | 体验版 | 真机验收 |

执行节奏：按时间规则（9-12、14-18 之外）执行；每阶段完成→体验版→验收→下一阶段。
