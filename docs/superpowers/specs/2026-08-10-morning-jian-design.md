# 明灯晨笺(早晚双笺)设计文档

> 状态:用户已确认(2026-08-10,逐节评审通过)
> 前置:目标用户深度调研(2026-08-10,15 次检索)+ P0 迭代规划
> 本文档为权威版本;桌面《易理明灯-P0功能详细方案.md》中的晨笺章节以此为准。

## 一、定位与差异化主张

> **星座号推的是"模板运势",我们推的是"一封古人写给你的信"。**
> 每天 7:30 一张可收藏的墨韵笺:今日宜忌 + 当日干支配《滴天髓》《穷通宝鉴》原典金句 + 一句"分类级轻私语"。
> 晚 23:00 一封"灯下晚安":明日运势预告 + 深夜陪伴入口。

差异化基础(别人抄不走):
- 276 万块古籍 RAG → 每日真原典金句(测测/豆包无垂类语料)
- L3 记忆 → 轻私语(记得你,但不点破)
- 墨韵美学 → 可收藏可截图,自带传播
- 服务号模板消息 → 每日稳定主动触达(小程序订阅消息做不到)

## 二、用户决策记录

| 决策点 | 结论 |
|---|---|
| 推送通道 | **服务号模板消息**(效果最好,不考虑成本;需注册/使用已认证服务号,企业主体最稳) |
| 推送方案 | **早晚双笺**(早晨笺 + 晚晚安) |
| 推送时间 | **用户自选**(晨笺 6:00-10:00、晚安 21:00-24:00 区间内自选,默认推荐 7:30/23:00 可改) |
| 推送授权 | **主动同意制**:用户主动开启+选时+确认才推送;未开启绝不发;随时可关 |
| 私语尺度 | **轻私语**(分类级信息,不点破具体事件/人物/原话) |
| 免费边界 | 基础版推送免费不降级;12 时辰完整版/笺匣无限/周报/晚安语音为会员权益 |

## 三、完整体验流程

```
(用户主动开启:引导页 → 选择推送时间 → 确认同意;未开启则全流程不触发)

用户选定时间(如 7:30)服务号模板消息「今日晨笺」(文字版)
   ↓ 点击
小程序今日页 → 完整墨韵晨笺卡(12 时辰条/原典展开/轻私语/今日小问)
   ↓ 收藏
笺匣(收藏页"笺"分类,自动归档,可回看)
   ↓ 用户选定时间(如 23:00)
服务号模板消息「灯下晚安」(明日运势预告+深夜陪伴入口)
```

### 早间晨笺(模板消息文字版)
```
易理明灯 · 今日晨笺
八月初十 · 庚申日
宜:出行 洽谈 早起 | 忌:借贷 熬夜
"申月金旺,逢土生扶,反为有用之才。"——《穷通宝鉴》
近日心事多与事业有关,今日宜主动一步。
[查看完整晨笺 →]
```

### 晚间晚安(模板消息)
```
明灯 · 夜话
夜深了,灯还亮着。明日财星入库,宜静不宜动。
睡个好觉,明日自有分晓。
[点一盏灯,说说话 →]
```

### 小程序内晨笺卡(点击后完整版)
- 完整 12 时辰吉凶条(可滑)
- 原典金句展开(书名+原文+白话解释,来自古籍 RAG)
- 轻私语一行 + "今日小问"(固定句式,如"今天最想做成的一件事是什么?")→ 点击进对话
- 右下角"今日印"(节气印)+ 收藏钮

### 订阅管理
- 设置页"消息订阅"区:晨笺/晚安开关、个性化私语开关(关闭后退回纯金句模式)

### 推送授权与时间自选(用户红线,必做)
- **授权同意制**:推送必须用户**主动开启**——小程序内"开启明灯晨笺"引导页:用户点"开启"→ 选择推送时间 → 确认后才开始推送;**未开启、关闭后、或未完成引导,一律不推送**(绝不默认发送)
- **时间自选**:晨笺推送时间由用户选择(建议区间 6:00-10:00,默认推荐 7:30 但用户可改);晚安时间同样自选(建议区间 21:00-24:00,默认推荐 23:00 可改)
- **随时可改/可关**:设置页随时改时间、一键关闭;关闭后当天即停,不再发
- **引导文案明确告知**:开启页写明"每天早/晚一条运势推送,可随时关闭"——不得使用误导性话术

## 四、内容生成机制

### 古籍金句管线(每日 0 点预生成次日)
```
① 计算次日干支/五行(引擎)
② 干支+五行作查询 → RAG 检索 → 候选 20 句
③ 规则筛选:真出自古籍(有书名) / 与当日宜忌呼应 / 30 天内不重复 / 15-40 字
④ LLM 核对:金句是否支持今日宜忌,不匹配换下一句
⑤ 兜底:无合格金句 → 当日只出宜忌,不出金句(宁缺毋滥,绝不编造)
```

### 轻私语管线
```
① L3 记忆召回:取最相关的 1 条(事业/感情/健康分类)
② 分类模板(绝无具体事件细节):
   事业:"近日心事多与事业有关,今日宜主动一步。"
   感情:"心中若有放不下的人,今日宜先与自己和解。"
   健康:"近来易倦,今日宜早歇,养足精神再出发。"
③ 无记忆 → 通用句("今日诸事,宜缓不宜急")
④ 红线:只出分类级信息;不点名事件/人物;不引用原话;用户可一键关闭
```

### 今日小问
- 从轻私语主题生成,固定句式,点击直达对话页(推送→对话入口)

## 六、技术实现

### 组件
```
① 推送服务(新):服务号模板消息封装
   - 模板:晨笺/晚安(服务号后台申请,类目匹配)
   - 定时:7:30 / 23:00(可配置,避开整点)
   - 发送:服务号 openid(需小程序↔服务号账号绑定,unionid 标准能力)
② 金句管线(新):干支 → RAG → 规则筛选 → LLM 核对 → 预生成
③ 轻私语管线(新):L3 召回 → 分类模板 → 红线校验
④ 晨笺卡前端(新):今日页顶部晨笺卡
⑤ 笺匣(改):收藏页新增"笺"分类
⑥ 订阅管理(改):设置页"消息订阅"区
⑦ 账号绑定(新):小程序内引导关注服务号并绑定
```

### 依赖与风险
- 服务号注册/认证(用户侧;个人主体类目受限,企业主体最稳)
- 模板消息无限发(合规,早晚各一)
- 金句质量:宁缺毋滥兜底

### 实现细节补充
- **按用户偏好时间调度**:定时任务按"用户选择的推送时间"分组调度(如 7:30 组/7:45 组…),不是全局固定时间;内容 0 点预生成,发送时按组取用
- **模板消息字数**:服务号模板消息正文有长度限制,晨笺文字版控制在 3-4 行内(宜忌一行+金句一行+私语一行+落款),超出内容引导进小程序看完整版
- **发送失败静默处理**:用户取关服务号/拒收 → 发送接口报错,静默停止该用户后续推送,设置页显示"订阅已失效"状态,不打扰
- **账号绑定流程**:小程序内引导页 → 展示服务号二维码/跳转关注 → 通过 unionid 绑定小程序账号与服务号 openid;绑定成功才算"开启"
- **时区**:统一北京时间,节假日不特殊处理(保持每日推送)
- **新用户默认态**:未绑定/未开启 = 完全不推送;晨笺卡在小程序内仍展示(今日页顶部),只是无推送触达

### 工作量(3-4 天,三版同步)
| 部分 | 天数 |
|---|---|
| 后端:推送+定时+账号绑定 | 1.5 |
| 后端:金句管线+私语管线 | 1 |
| 前端:晨笺卡+笺匣+订阅设置(三版) | 1.5 |

### 与现有功能关系
- 复用:RAG / L3 记忆 / 收藏页(笺匣)/ 设置页 / 今日页
- 不新建 tab、不改变现有导航

## 七、成功标准

1. 订阅授权转化率 ≥ 40%
2. 晨笺点击打开率 ≥ 15%(行业模板消息 5-10%)
3. 晨笺收藏率 ≥ 8%
4. 晚安→深夜陪伴入口点击率 ≥ 20%

## 八、明确不做(本功能范围内)

- 不做小程序订阅消息每日推送(能力限制)
- 不做服务号图文群发(每月 4 次限制,不适用每日)
- 不做"点破具体事件"的贴身私语(隐私红线)
- 不做金句编造兜底(宁缺毋滥)
