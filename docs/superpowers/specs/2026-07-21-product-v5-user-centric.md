# 易理明灯 v5.0 "以用户为中心" 产品规划

> 版本: v5.0 | 日期: 2026-07-21 | 基于 15+ 次搜索调研
> 前置版本: v3.1（RAG v4.0 架构已就绪）
> 版本策略: v3.1 独立保留（git tag），v5.0 从 main 分支演进

---

## 一、版本策略

```
v3.1 (当前) — RAG 架构升级完成，BGE-M3 知识库就绪
  │
  └─ git tag: v3.1-rag-stable
  │
  ▼
v5.0 (本规划) — 用户驱动产品重构
  ├─ Phase 1: 信任基石（排盘准确 + 定价透明）
  ├─ Phase 2: 决策引擎（场景化分析 + 行动建议）
  ├─ Phase 3: 情感陪伴（记忆系统 + 命运订阅）
  ├─ Phase 4: 社交裂变（可视化报告 + 合盘）
  └─ Phase 5: 出海准备（国际化）
```

**版本隔离原则**：
- v3.1 代码打 tag 后独立保留，任何时刻可回滚
- v5.0 每个 Phase 独立分支，合并前必须通过验收
- 每个 Phase 有独立的 API 版本号（/api/v1/ → /api/v2/）

## 二、Phase 1：信任基石（P0，3-4 周）

### 目标
用户第一次使用就感觉"这个靠谱"

### 功能清单

#### 1.1 排盘准确度保证
**验收标准**：
- [ ] 与问真八字对比 500 例，排盘一致率 ≥ 99.5%
- [ ] 同一八字同一问题，10 次查询结果 100% 一致
- [ ] 支持真太阳时矫正，覆盖全国 300+ 城市
- [ ] 支持阳历/农历/时辰三种输入方式
- [ ] 错误输入（如 2月30日）有明确中文提示

**技术方案**：规则引擎独立计算，不依赖 LLM。LLM 只做解读不做计算。

#### 1.2 透明定价体系
**验收标准**：
- [ ] 首页明确展示：免费功能 vs 付费功能清单
- [ ] 每次消费前弹窗确认金额，无隐藏消费
- [ ] 用户可查看完整消费记录
- [ ] 新用户赠送 3 次完整解读体验
- [ ] 付费页面底部标注"本次分析成本约 ¥0.03，我们收费 ¥X.XX"

**反割韭菜声明**（产品内展示）：
"我们不做化灾改运，不卖转运符咒，不算命定生死。我们只做基于传统命理学的分析和建议。"

#### 1.3 排盘结果可复现
**验收标准**：
- [ ] 每次解读标注"解读版本号"和"生成时间"
- [ ] 用户可查看历史解读记录
- [ ] 同一输入任何时候查询结果一致

## 三、Phase 2：决策引擎（P0，4-6 周）

### 目标
用户看完就知道"该怎么办"

### 功能清单

#### 2.1 场景化入口
**验收标准**：
- [ ] 首页不是"请输入八字"，而是 6 个场景卡片：
  - 💼 我该不该换工作
  - ❤️ 这段感情能走下去吗
  - 💰 今年财运如何
  - 🏥 健康需要注意什么
  - 🏠 适合搬家/买房吗
  - 🤝 和他/她合不合
- [ ] 每个场景引导用户输入必要信息
- [ ] 场景覆盖率达竞品（测测/准了）的 80%+

#### 2.2 结构化解读报告
**验收标准**：
- [ ] 每份报告固定三层结构：
  1. **核心结论**（3 句话以内，用户一眼看懂）
  2. **分项分析**（财运/事业/感情/健康，用户关心的部分突出显示）
  3. **行动建议**（3-5 条具体可执行的建议，带时间框架）
- [ ] 每条行动建议格式："[时间窗口] 做什么 + 为什么 + 怎么判断效果"
  例："未来三个月财运偏弱。建议避免大额投资，优先还清信用卡。关注教育/医疗行业的机会，尤其是农历八月后。"

#### 2.3 追问能力
**验收标准**：
- [ ] 用户可对报告中任意结论追问
- [ ] AI 能关联上下文回答（不从头开始）
- [ ] 追问次数不限制（免费功能）

## 四、Phase 3：情感陪伴（P1，4-6 周）

### 目标
用户每天都想打开

### 功能清单

#### 3.1 用户记忆系统
**验收标准**：
- [ ] 用户再次登录时 AI 打招呼："上次聊到你的感情问题，最近有变化吗？"
- [ ] 记忆内容：八字信息、对话历史、关注问题、情绪状态
- [ ] 用户可随时查看/删除记忆数据
- [ ] 跨会话上下文保留 30 天

#### 3.2 命运日历
**验收标准**：
- [ ] 每日推送今日运势（宜/忌/情绪提醒）
- [ ] 关键节点预警（换大运、流年重要星象）
- [ ] 用户可选择推送频率（每日/每周/仅关键节点）
- [ ] 推送内容 80% 以上用户觉得"有用"（以打开率为指标）

#### 3.3 情绪感知
**验收标准**：
- [ ] 通过用户语言分析情绪状态（焦虑/迷茫/兴奋/低落）
- [ ] 在命理解读中适配情绪："你现在可能比较焦虑，但八字显示..." 
- [ ] 识别到极端情绪时引导到专业帮助
- [ ] 不做心理咨询声明（避免合规风险）

## 五、Phase 4：社交裂变（P1，3-4 周）

### 目标
用户愿意分享，产品自带传播

### 功能清单

#### 5.1 可视化命运报告
**验收标准**：
- [ ] 运势K线图（折线图显示过去/未来运势趋势）
- [ ] 人格雷达图（五行属性可视化）
- [ ] 大运时间线（交互式人生阶段图）
- [ ] 每份报告右上角"分享"按钮
- [ ] 分享图片自动生成产品水印和二维码
- [ ] 报告设计对标 Apple Health / Spotify Wrapped

#### 5.2 合盘社交
**验收标准**：
- [ ] 支持两人生辰八字合盘
- [ ] 合盘报告包含：匹配度评分、优势互补分析、潜在冲突预警
- [ ] 合盘结果可双方确认后分享
- [ ] 合盘场景覆盖：情侣、合伙人、亲子

## 七、技术架构（全 Phase 共享）

```
用户界面层
    │
    ▼
场景路由层（Phase 2）
    │
    ├── 八字排盘引擎（规则引擎，不依赖 LLM）
    ├── 紫微排盘引擎
    ├── 解梦引擎
    └── ...
    │
    ▼
RAG 知识库层（v4.0 已就绪）
    │
    ▼
LLM 生成层（DeepSeek API）
    │  输入：排盘结果 + RAG 知识 + 用户上下文 + 产品模板
    │  输出：结构化解读报告
    │
    ▼
记忆系统（Phase 3）
    │
    ▼
可视化引擎（Phase 4）
```

## 八、全局验收标准

每个 Phase 交付时，以下标准必须全部通过：

| # | 标准 | 测量方式 |
|---|------|----------|
| 1 | 排盘与问真八字一致率 ≥ 99.5% | 自动对比 500 例 |
| 2 | 同一查询结果 100% 一致 | 重复查询 10 次 |
| 3 | 解读报告含"结论→分析→建议"三层 | 人工抽检 50 例 |
| 4 | 定价信息页面前端可见 | 人工检查 |
| 5 | 无隐藏付费入口 | 人工检查 |
| 6 | API 响应时间 < 60s（八字解读） | 自动监控 |
| 7 | API 响应时间 < 5s（非八字查询） | 自动监控 |
| 8 | 错误率 < 1% | 自动监控 |
| 9 | 用户记忆跨会话保留 | 测试用例 |
| 10 | 分享图片可正常生成 | 测试用例 |
