## 一、设计系统

### 1.1 色彩体系

```
主色调: #1a1a2e (深靛蓝) — 神秘、专业、中性，男女皆宜
强调色: #c9a96e (暗金) — 温暖、高级，不刺眼
背景: #fafaf9 (暖白) / #0f0f14 (深色模式)
文字: #1c1917 (暖黑) / #e8e4e0 (深色模式)
次级文字: #78716c (暖灰)
卡片: #ffffff / #1a1a24
分割线: #e7e5e4 / #2a2a34
```

**为什么不用 AI 紫色**: 紫色在算命产品中太泛滥（测测、准了都是紫色系），用户产生"又一个算命 App"的认知。深靛蓝+暗金区分明显。

**为什么不用暖米色+黄铜色**: 调研报告禁止的 premium-consumer 默认调色板。深靛蓝走冷奢华路线。

### 1.2 字体

```
标题: PingFang SC Semibold (系统默认，零额外加载)
正文: PingFang SC Regular
数字: SF Mono (运势分数、五行数值)
字号阶梯: 11/13/15/17/20/24/32px
```

### 1.3 圆角

```
卡片: 16px
按钮: 24px (全圆角 pill)
输入框: 12px
头像: 50% (圆形)
Tab 图标: 无圆角
```

**一致性规则**: 所有交互元素 pill 按钮，所有容器 16px 圆角，所有输入 12px。不混用。

### 1.4 间距

```
页面边距: 16px
卡片内边距: 20px
段落间距: 12px
Section 间距: 24px
元素间距: 8px 基础网格
```

### 1.5 图标

使用小程序内置 icon 或自定义 SVG。禁止 emoji 作为图标。

## 三、动效规范

| 类型 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 页面切换 | 300ms | ease-out | Tab 切换 |
| 卡片出现 | 400ms | spring(1, 0.8) | 列表加载 |
| 数字滚动 | 800ms | ease-out | 运势分数 |
| 按钮按压 | 100ms | ease-in-out | scale 0.97 |
| 气泡出现 | 300ms | ease-out | 对话消息 |
| loading | 循环 | 无 | skeleton shimmer |

**禁用动效**:
- 禁止弹跳/回弹过多 (max 1 bounce)
- 禁止无限循环动画（除 loading 外）
- 禁止 parallax 滚动效果（小程序性能）
- `prefers-reduced-motion` 时所有动效降级为 instant

## 四、验收清单

### 设计验收 (10 项)

- [ ] 色彩精确匹配：深靛蓝 #1a1a2e，暗金 #c9a96e，暖白 #fafaf9
- [ ] 字体无额外加载：仅使用系统 PingFang SC
- [ ] 圆角一致性：卡片 16px，按钮 24px，输入 12px
- [ ] 深色模式完整覆盖：4 个 Tab 全部支持 dark mode
- [ ] 无 emoji 作为图标使用
- [ ] 无 AI 紫色/渐变/发光效果
- [ ] 无 em-dash `—` 出现在任何 UI 文案中
- [ ] 按钮文字不换行（桌面预览时）
- [ ] 4 个 Tab 的视觉风格统一
- [ ] 分享卡片包含品牌标识和二维码

### 功能验收 (10 项)

- [ ] Tab 1 今日：运势分数、宜忌、建议、趋势图
- [ ] Tab 1 左右滑动切换日期
- [ ] Tab 2 对话：场景选择器横向滚动
- [ ] Tab 2 消息气泡、typing 指示器、结构化报告展示
- [ ] Tab 3 报告：列表加载、详情页、分享按钮
- [ ] Tab 4 我的：八字档案显示、设置项可点击
- [ ] 微信登录流程：wx.login → openid → JWT
- [ ] 所有 API 调用走 HTTPS
- [ ] 用户数据加密存储（wx.setStorage 前加密）
- [ ] 免责声明在所有页面底部可见

### 性能验收 (5 项)

- [ ] 首屏加载 < 2s
- [ ] Tab 切换 < 300ms
- [ ] 对话消息发送到显示 < 1s（不含 AI 分析时间）
- [ ] 内存使用 < 100MB
- [ ] 无页面闪烁或布局跳动

### 安全验收 (5 项)

- [ ] 用户 birth data 不在本地明文存储
- [ ] API token 过期自动刷新
- [ ] 敏感操作（导出/删除）需要二次确认
- [ ] 聊天记录加密传输
- [ ] 隐私设置页包含完整的数据删除功能

### 可访问性验收 (3 项)

- [ ] 文字对比度 WCAG AA (4.5:1)
- [ ] 触控区域最小 44×44px
- [ ] 非文本内容有替代文字
