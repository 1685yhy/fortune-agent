# 易理明灯 v6.0 — 今日运势首页重设计规格

> 旗舰页：仪式感 + AI智能化 + 东方道家美学
> 验证后铺开到 3 Tab(今日/命理/我的)

---

## 一、产品定位

### 核心体验
用户每天早上打开小程序，像抽一张神谕卡——**太极旋转动画 → 运势圆环绽放 → 今日命理徐徐展开**。整个过程庄重、有期待感、不赶时间。

### 物理场景
清晨 7:00-9:00，用户在家刚起床或通勤途中，独处，想看一眼今天运势。光线柔和，需要暗色沉浸式体验但文字清晰可读。

### 竞品对标
- 超越"问真八字"（工具感太强、无仪式体验）
- 超越"测测"（社区太重、设计平庸）
- 参考 Apple Health 的圆环 + Headspace 的仪式入场

## 四、详细功能规格

### 4.1 入场动画

**时序**：
1. 页面 `onReady` → 触发入场
2. 太极图从中心旋转放大（0→800ms）
3. 太极淡出，粒子从太极位置扩散
4. 粒子聚拢为运势圆环（600ms）
5. 圆环稳定，分数从 0 翻滚至目标值（800ms）
6. 卡片内容 stagger 淡入（400ms，子元素各延迟 100ms）

**实现**：
- 太极旋转 + 粒子 → Canvas 2D API
- 分数翻滚 → JS setData（50ms 间隔）
- 卡片淡入 → WXSS animation（`opacity 0→1, translateY 20px→0`）

**降级**：若 `reduceMotion` 设置，跳过动画，直接显示最终状态。

### 4.2 运势分数环

**Canvas 绘制**（替代 conic-gradient）：
- 背景环：`--bg-card` 色，线宽 6px
- 进度环：`--gold` 色，从 12 点钟顺时针绘制
- 环内居中：大号分数数字 + 等级文字
- 圆环尺寸：200×200 rpx

**刷新时机**：
- 每天首次打开自动计算
- 下拉刷新重新获取
- 切换日期（左右滑动）触发对应日期计算

### 4.3 AI 今日解读

**数据来源**：
- 后端 `/api/calendar/today` 返回 `personal_advice` 字段
- 基于用户八字日主 + 今日干支的五行生克生成
- **禁止**通用模板——每个用户的解读必须不同

**展示**：
- 字体略大（`--font-lg`，17px）
- 颜色：`rgba(232,228,224,0.85)`（暗底浅色）
- 最多两行，超出省略

### 4.4 时辰运势时间线

**交互**：
- 横向 `scroll-view`，12 个时辰平铺
- 当前时辰高亮（金色边框）
- 点击某时辰 → 下方展开时辰详情卡片
- 详情卡片包含：时辰干支、宜忌、简短建议

**数据计算**：
- 基于今日日柱 + 时辰地支的五行关系（纯规则引擎，无需 API）

### 4.5 幸运三连

三张横向卡片，每张包含：
- 图标（Canvas 绘制简单图形或纯文字符号）
- 数值/名称
- 一行小字说明

### 4.6 宜忌

- 宜（绿色/玉色标记）+ 忌（朱砂红标记）
- 每条后面可附时间建议（如 "（巳时）"）
- 最多各 3 条

### 4.7 本周运势预览

- 7 日迷你走势：用一个简单的 Canvas 折线图或条形图
- 显示每日分数变化趋势
- 点击某日可切换到该日运势

### 4.8 心情记录

- 4 个表情按钮，横向排列
- 点击有 scale 弹跳反馈
- 数据存储：调用 `/api/user/mood`（待新增）
- 底部显示：本月心情统计（若有数据）

## 五、AI 智能化点

### 5.1 个性化解读
- 基于用户八字日主 + 今日天干地支的五行生克
- 不是模板，每次不同
- 速度要求：< 2s 返回

### 5.2 时辰运势
- 基于日柱 + 时辰地支的规则引擎
- 12 时辰全部预计算，无需额外 API 调用

### 5.3 心情追踪
- 记录每日心情 → 月视图情绪曲线
- 与流月运势交叉对比 → "你的心情波动和流月运势的关联度"

## 六、技术约束（微信小程序平台）

### 6.1 性能
- Canvas 动画 ≤ 60fps
- 首屏渲染 ≤ 1.5s
- setData 单次 ≤ 64KB
- 图片懒加载
- 不加载外部 Web 字体

### 6.2 兼容
- 基础库 ≥ 3.0.0
- iOS + Android 真机测试通过
- 暗色模式自动跟随系统
- `prefers-reduced-motion` 支持

### 6.3 代码规范
- 所有颜色使用 CSS 变量（禁止硬编码）
- WXML 禁止 `wx:if` 中调用方法
- WXSS 禁止 `*` 选择器、`conic-gradient`
- JS 禁止 `Buffer`、`getUserProfile`（已废弃）
