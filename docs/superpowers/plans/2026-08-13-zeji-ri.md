**Goal:** 实现"明灯择吉日":对话式选日(用户说"下个月搬家帮我选日子"→ 3 个吉日卡:宜忌/吉时/方位/一句理由)→ 选定 → 办事清单(6 场景模板+LLM 定制,可勾选/备注)→ 主动同意制提醒(前1天21:00+当天7:30,服务号模板消息,复用晨笺通道)→ 三版小程序同步。

**Architecture:** 复用并增强既有 `ZeriEngine`(src/engines/zeri.py,已接入对话工具链"择日")——补 6 场景规则库、三层评分(场景/个人/实用)、多日窗口 Top3 扫描、吉时方位、喜用神适配;新清单管线 `src/engines/zeri_checklist.py`(6 场景模板+LLM 定制+免费/会员切分);新 DAO `src/storage/zeri_dao.py`(zeri_plans 选日清单落库 + zeri_prefs 提醒订阅 + zeri_quota 换一批次数);新 API `src/api/zeri.py`(选日/清单/历史/订阅/换一批);提醒 worker 复用 `_send_jian_batch` 模式(前1天21:00/当天7:30 两档模板消息,2 条封顶);前端三版(墨韵为准)新增今日页入口卡(抄 hehun 入口卡)+ 择吉日引导页 + 吉日卡页 + 清单页 + 设置页"择日提醒"开关。

**Tech Stack:** FastAPI + sqlite(现有 dao 模式)+ lunar-python(干支/宜忌/冲/建除,ZeriEngine 已依赖)+ deepseek-flash(Anthropic 兼容端点,复用 `src/llm/client.deepseek_anthropic_completion`)+ 服务号模板消息(复用 wechat_mp,MP_* env 未配时静默休眠)+ 小程序原生(三版)+ 测试 scripts/test_*.py(TestClient+断言,无网络依赖)。
