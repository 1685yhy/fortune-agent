## A. 夏令时 1986-1991 口径——取证结论：问真默认不调整（零引擎改动 + 锁定测试）

接口：`bzapi3.iwzbz.com/getbasebz8.php`，params `d=YYYY-MM-DD HH:MM&s=性别&today=…&vip=0&yzs=0&pqf=0`

### A2. 取证结论

1. 问真 getbasebz8 API 对夏令时区间（含首尾日）出生**默认不减 1 小时**：07:30 原样出辰时盘（若减 1h 必出已直查到的 06:30 卯时盘，API 具备区分能力且实测给出原样盘——证据闭环，非"盘面巧合不可区分"）。
2. 问真 API 无夏令时开关参数（探针全部无响应）。已知可解码参数仅 d/s/today/vip/yzs/pqf。
3. 本引擎口径对齐结论：**daylight_saving 默认关 = 问真默认（忽略）**，G5 起的现行为即正确 → **A 项实现 = 零引擎改动 + 锁定测试**（防未来任何人"好心"加默认 DST 逻辑而偏离问真；可选开关机制保留并锁其 −1h 输出与问真 −1h 对照盘逐字一致）。
4. 证据缺口注记：App 客户端（非 API）是否存在夏令时勾选项无法经 API 验证（G5 同样未能解码）；若未来取证到 App 端确有开关，其默认态仍须与此一致方不违反问真一致性铁律。本批不改任何开关默认值。

## B. 换运切段口径（k11c 遗留）——统一为精确交运时刻切段

### B1. 现状差异核对

- current_stage_facts（k11 建）：当前大运段 = dayun 中**最后满足 sui ≤ 虚岁** 的段（虚岁 = 公历年差 + 1 → 1 月 1 日即满岁）。起止年份展示走 jiaoyun.years[].year（交运年，立春界定）。
- 排盘卡大运展开（R2 起运分解 / _calc_jiaoyun）：jiaoyun.years[] 每条含 **time = 精确交运时刻**（出生 + 起运分解 → 逢交运日同刻，如 golden 1999-05-13 长春男 2001-09-25 09:25 起运，此后每逢 9-25 09:25 换段），问真口径。
- 差异实证（golden 1999-05-13 长春男）：虚岁 23 于 **2021-01-01** 即满 → 旧口径元旦起报"当前大运丙寅"；而精确交运时刻为 **2021-09-25 09:25**。同理起运前（虚岁 3 自 2001-01-01 满）旧口径提前 ~9 个月报戊辰。→ **不一致成立**（虚岁岁首切段早于交运日，最坏提前近一年）。

### B2. 统一方案（已实现）

current_stage_facts 段选改为**精确交运时刻切段**（与排盘卡同源，问真锚）：
- 当前段 = jiaoyun.years[] 中 time ≤ now 的最后一条所对应 dayun 段（time 与排盘卡 jiaoyun 展开逐字同刻；交运时刻整点起算新段已交）。
- now 早于首段交运时刻（含起运前）→ **无当前大运段**（缺键契约不变，事实包该行缺席）。
- jiaoyun 缺失 / years 无 time 字段（旧数据、手工构造）→ 兜底虚岁段选（k11 原行为，兼容锁定）。
- 越过交运年表末段（_calc_jiaoyun years 只列 9 段 ≈ 90 岁档）→ 段内保持末段，再往后按虚岁口径兜底（表外近似，注释注记）。
- 起止年份展示仍用交运年（jiaoyun.years[].year 立春界定，兜底 出生年+sui−1），与 paipan 大运展开公式同款，不改。
- 消费端（bazi_formatter 事实包行、advisor 注入）字段名不变，零改动。

### B3. 边界测试覆盖

- 虚岁岁首 vs 交运日先后：2021-01-01（虚岁 23 满、交运 09-25 未到）→ 仍丁卯段（旧口径此日已错报丙寅）；2031-01-01 → 仍丙寅段。
- 交运当天出生时刻前后：2021-09-25 09:24 → 丁卯；09:25 整点 → 丙寅；09:26 → 丙寅。
- 起运前/后：2001-09-25 09:24 → 无当前段（缺键）；09:26 → 戊辰（2001-2010）。
- 表末/表外：2081-09-25 09:26 → 虚岁 83 段；2095 → 虚岁兜底进 93 岁档（己未，表外近似）。
- 无 time 字段兜底 = k11 原行为（回归锁定 丙寅/27/28）。
