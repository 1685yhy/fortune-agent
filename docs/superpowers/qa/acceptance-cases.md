# 易理明灯 — 黑盒验收用例库（QA 独立验收用）

> 2026-08-22 建立 · PM 拍板：验收必须独立于开发，测试角色不读实现代码，对照本库逐条测。
> 用例来源：总规划 spec（2026-08-19-total-plan-design.md）/ UX 审查清单 / PM 真机反馈 / 性能标准。
> 判定：**PASS / FAIL / 阻塞**（环境原因不可测，需标注）。证据驱动：每条必须有响应/截图/日志/实测数据。
> 执行者：qa-tester 角色（.claude/agents/qa-tester.md）。触发：功能合入、每次体验版发布前全量或按域回归。

## 域 1：性能与渲染（PM 点名：加载慢/重渲染/卡顿必须按标准测）

**性能标准（全项目通用）**：
- 页面冷启动（首次进入）：≤ 2 秒出现首屏内容
- 页面切换/切回：≤ 0.5 秒可交互，**不得重新加载整页内容**（应缓存或增量更新，不得白屏闪烁）
- 对话首字时间：即时回复 ≤ 2s；深度回复 ≤ 10s（现有 [timing] 实测基线：instant 1.3-2.0s / main 9.7-16.9s）
- 列表滚动：无肉眼可见掉帧/卡顿；滚动不被意外拽回

| 编号 | 验收标准 | 步骤 | 期望结果 |
|---|---|---|---|
| AC-PERF-001 | **今日页进入不重渲染** | 进入今日页 → 切到其他 tab → 切回今日页，观察内容与网络请求 | 内容立即显示（缓存复用），**无白屏、无重新加载动画、无重复网络请求**；若必须刷新，须有骨架屏/缓存占位而非空白卡顿 |
| AC-PERF-002 | 各页面冷启动 | 逐个进入：对话/今日/测算/我的/排盘/万年历/名人库/多盘对比/合盘/择吉/取名/灵签 | 每页首屏 ≤2s 出现，加载态（骨架/菊花）即时显示，不白屏超过 2s |
| AC-PERF-003 | 对话首字时长 | 发送普通问题，计时到首个字出现 | 即时回复 ≤2s；深度回复 ≤10s；超过要有进度反馈（"深度思考中"）而非静默 |
| AC-PERF-004 | 列表滚动流畅 | 名人库（2807 条）/历史/收藏列表上下快速滑动 | 滚动跟手、无卡顿掉帧、触底加载正常触发不重复加载 |
| AC-PERF-005 | 图片/长列表不卡 | 分享图生成、灵签图、名人详情长页 | 生成/渲染不卡死主线程；超长内容有节流或降级而非白屏 |
| AC-PERF-006 | 后端接口响应 | 核心接口（排盘/今日/对话/各功能页）实测响应时间 | P95 < 1.5s（本地 8767 实测） |

## 域 2：数据一致性（PM 反馈：页面显示与档案/答案不一致）

| 编号 | 验收标准 | 步骤 | 期望结果 |
|---|---|---|---|
| AC-CONS-001 | 档案三处一致 | 排盘页填生辰 → 我的页看档案 → 对话里问"我的档案" | 三处显示的出生日期/时辰/性别**完全一致**；来源唯一（以最新档案为准） |
| AC-CONS-002 | 对话复用档案 | 已有档案的用户，对话里问"我的运势/我的八字" | 系统**直接使用已存档案**回答（不重新让用户报生辰、不重排冲突盘）；无档案时引导建档 |
| AC-CONS-003 | 排盘结果一致 | 同一生辰在不同入口（表单排盘/对话排盘/历史记录） | 四柱/大运/起运**逐项一致**（真太阳时开关一致的前提下） |
| AC-CONS-004 | 修改后全局生效 | 更新档案出生信息后，重新进入已看过的排盘结果/今日页 | 新数据生效；旧快照明确标注生成时间，不混用 |
| AC-CONS-005 | 多盘对比数据同源 | 多盘对比用的双方八字与各自档案一致 | 对比盘与单盘排盘结果一致，差异项有明确标注（晚子时/真太阳时口径） |

## 域 3：账号与安全（红线域，破坏性探测仅做检测不做攻击）

| 编号 | 验收标准 | 步骤 | 期望结果 |
|---|---|---|---|
| AC-SEC-001 | 退出登录真正生效 | 登录 → 退出 → 继续点任意功能 | 提示已退出，**不得静默自动重登**；重新登录后才能使用 |
| AC-SEC-002 | 注销账号可完成 | 设置 → 注销 → 按引导确认 | 流程走通（非报错）；注销后该账号无法再登录 |
| AC-SEC-003 | 越权不可达 | 用户 A 的 token 访问用户 B 的档案/收藏/历史/择日计划 | 全部拒绝（403/401），零泄露 |
| AC-SEC-004 | 数据脱敏 | 手机号绑定后的展示/日志 | 展示脱敏（138****0000）；接口不回传明文 |
| AC-SEC-005 | 隐私不落库 | 合盘 TA 生辰/取名生辰 | 仅存本机 localStorage，服务器零存储（按 spec 红线） |
| AC-SEC-006 | 额度不可绕过 | 免费用户超 15 条后继续对话 | 进入降级模式（不硬断、有提示）；择吉"换一批"必须扣额度且不能被参数绕过 |

## 执行要求
1. **独立执行**：qa-tester 角色不读实现代码；开发方不得代替判定
2. **全量回归**：每次体验版发布前跑全库；日常合入跑相关域
3. **缺陷闭环**：FAIL → 缺陷报告 → 开发修复 → **复测原用例** → 通过才算关
4. **覆盖率要求**：验收报告须注明"本次未测/阻塞"项与原因，不允许静默跳过
5. 新功能/新反馈 → 持续向本库**追加用例**（PM 反馈的问题必须沉淀为用例，防复发）
