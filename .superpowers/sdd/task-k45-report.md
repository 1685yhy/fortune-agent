## 1. 结论

**这是测试设计缺陷（小样本 × 免费判卷抽样噪声 × 阈值落在噪声带），不是产品缺陷。**

旧口径：3 条样本、单轮 15 维（人工对照 9 维），断言 `rate ≥ 0.5`。
实测单轮 rate mean 0.6167 / sd 0.0688 → 阈值距均值仅 **1.44σ** → 理论假红 ≈7.5%，
实测 1/12 轮 = 8%，改前 5 次实跑 1 红 4 绿。

修正（三条）：① 同批样本**重复判卷 k=3 轮**后池化（45 维 / 人工对照 27 维）；
② 阈值按实测分布定（含边距，实测数据见 §2/§3）；③ 判卷错误/空的样本按「不可用」处理
（重试 → 仍不可用整条排除，绝不按 0 分计）。

**结果：改后 5 次单跑全绿（§5）；假红 8% → ≲0.1%，对「rubric 修正被回退」的检出
29% → 80%（§6）——判别力未降，反而更强。**

## 3. 阈值依据（数据 → 阈值）

| 断言 | 新阈值 | 依据（全部实测） | 假红估计 |
|---|---|---|---|
| 聚合 rate | **≥ 0.45** | 0.6166 − 4.3σ；实测 2024 组合 min 0.4889 向下留 0.039 边距；bootstrap q0.1% = 0.4667 | **0.07%** |
| 聚合人工对照 rate | **≥ 0.45** | 0.6759 − 5.5σ；实测组合 min 0.5556 向下留 0.106 边距；bootstrap q0.1% = 0.5185 | **0.00%** |
| 单轮 rate 下限 | **≥ 0.25** | 实测 24 轮 min 0.400，mean − 5.3σ | ~0% |
| 可用人工对照维 | **≥ 18** | 2 轮量下限；判卷大面积不可用时显式失败（无法判定） | — |

**为什么低于旧名义线 0.5**（这是必须的，不是放水）：实测 k=3 最低组合 **0.4889 < 0.5**——
即 0.5 在聚合口径下仍会被实测尾部翻红；bootstrap 假红 0.64%。0.45 取「实测尾部再留边距」，
假红 0.07%，同时远高于「真退化」区间（见下）。

**判别力为什么没降**：
- 灾难性退化仍被拦：判卷全 0 分口径 rate ≈ 1/15 = 0.067；9 个人工对照维全崩而代理维全绿
  的上限 = 6/15 = **0.40 < 0.45**；判卷大面积不可用/解析全挂由「可用维数 ≥ 18」拦下。
- 定向退化（rubric 修正被回退）由人工对照断言拦下，见 §6 实测检出率 80%。

## 4. 改动内容（tests/test_eval_e6.py）

1. **k=3 轮聚合**：`_calibration_round()`（轮内 3 样本并行判卷）+ `_aggregate_calibration()`
   （池化：分母/命中数逐轮累加，等分母时等价于各轮 rate 均值）。
2. **不可用样本处理**：`_judge_usable()`（skipped / judge_error / 缺维 / 维级 judge_error
   → 不可用）+ `_judge_sample_with_retry()`（默认 2 次尝试）；不可用样本整条排除出统计、
   打印清单，可用人工对照维 < 18 时显式失败。
3. **阈值常量**（带实测依据注释）：`_CALIBRATION_ROUNDS=3`、
   `_CALIBRATION_JUDGE_ATTEMPTS=2`、`_CALIBRATION_MIN_DIRECT_DIMS=18`、
   `_CALIBRATION_MIN_RATE=0.45`、`_CALIBRATION_MIN_DIRECT_RATE=0.45`、
   `_CALIBRATION_MIN_ROUND_RATE=0.25`。
4. **结构断言不放宽且加强**：单轮 `direct["n"] == 9`（3 条全可用时）、聚合
   `direct["n"] == 27`、`total_dims == 45`、每样本 5 维逐轮核对；新增单轮 rate 硬下限、
   聚合人工对照下限、可用维数下限。
5. **docstring 写全**：实测分布、阈值依据、旧口径假红/检出对比、以及
   「这不是放宽判别力而是消除抽样噪声」的说明。
6. **新增 3 个 mock 单测（零 LLM 调用）**：
   `test_calibration_round_excludes_unusable_not_zero`（错误不按低分计）、
   `test_calibration_round_retries_transient_judge_error`（瞬时错误重试）、
   `test_calibration_aggregation_pools_rounds_and_skips_none`（聚合数学）。
7. `RUN_EVAL_E6_FULL_CALIBRATION=1` 全量路径（30 条 150 维）**不变**：维度大、无抽样噪声问题。

## 6. 判别力验证：rubric 修正被回退（对照实验）

方法：`/tmp/k45_control.py`——把 `judge.CALIBRATION_FIX_ANCHORS` 从判卷 system prompt

| | 正常 rubric（24 轮） | 回退 rubric（7 轮） |
|---|---|---|
| 单轮 rate mean | 0.6167 | 0.514 |
| 单轮 direct mean | 0.6759 | **0.397** |
| k=3 聚合 rate 组合 min | 0.4889 | 0.444 |
| k=3 聚合 direct 组合 min | 0.5556 | 0.259 |

| 判据 | 假红（正常 bootstrap） | 检出（回退 rubric） |

| 聚合 rate ≥ 0.45 | 0.07% | 8.6%（3/35） |

→ **假红降两个数量级，检出提升到 ~3 倍。** 保留 `direct` 断言的理由也在这里：聚合 rate 被
6 个代理维稀释，单独用它抓不住 rubric 回退（只 8.6%）。
